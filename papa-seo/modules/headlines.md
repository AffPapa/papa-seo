# Заголовки: title, H1, description, первый абзац

Делает title, H1, meta description и первый абзац страницы так, чтобы человек в выдаче понял, что найдёт, и нашёл это после клика. Обещание заголовка равно содержанию страницы: кликбейт поднимает клики и роняет доверие. Проверку уже существующих тегов на сайте (дубли, пустые, длина в пикселях) делает `on-page.md`; здесь — как их написать.

**Когда грузить:** режимы `write`, `landing`, `refresh`, `fix`; «придумай title», «перепиши заголовок», «почему низкий CTR», «сниппет некрасивый», «нужен H1».

**Входы:** главный запрос и формулировки, которыми ищут (из `semantics.md`, GSC/Вебмастера или выдачи); содержание страницы или бриф; тип страницы (`references/page-types.md`); текущие title/description/H1, если страница есть (`python3 scripts/page_facts.py <url>`); выдача по запросу (`serp.md`); бренд и запреты проекта (`.papa-seo/project.md`); для refresh — запросы и CTR страницы (`measure.md`).

## Шаги

1. **Выдача как бриф.** Прочитать заголовки первых 10 результатов: какие слова повторяются (это язык запроса), какие обещания дают, что общее у всех. Свой заголовок должен отвечать тому же интенту и чем-то отличаться — фактом, а не прилагательным.
2. **Что обещаем.** Одной фразой: что человек получит на странице. Эта фраза — основа для title, H1 и первого абзаца. Если её не удаётся сформулировать без «лучший» и «полный», у страницы нет отличия — сказать об этом.
3. **Title.** Запрос в форме, в которой его ищут, ближе к началу; уточнение, которое отличает страницу (год проверки, число вариантов, город, формат — только если это правда на странице); бренд коротко через разделитель, если так принято на сайте. Свой у каждой страницы, без шаблонных повторов (facts-2026 §5).
4. **Длина.** Лимита длины нет, обрезка — по ширине экрана (facts-2026 §5, `folklore.md`). Главное — в начале, чтобы смысл остался после обрезки. Ширину в выдаче проверять в `on-page.md`, а не считать символы на глаз.
5. **H1.** Об одном с title, но может быть длиннее и человечнее; не копия title слово в слово, если title содержит бренд и уточнения. Обычно один H1 на страницу: так проще читателю.
6. **Description.** Что внутри страницы и для кого, с одним фактом (цена «от», число вариантов, срок, город) — если он есть на странице. Google берёт description, когда он точнее текста страницы, и может заменить его своим (facts-2026 §5): переписанный поисковиком сниппет — повод сверить description с содержанием.
7. **Первый абзац.** Сразу отвечает на запрос из title: суть, условие, главное число. Без вступления о важности темы. Он же часто становится сниппетом.
8. **Уровень осведомлённости читателя** (классическая схема копирайтинга): человек не знает о проблеме → знает проблему → знает решения → знает наш продукт → готов купить. Чем ближе к покупке, тем конкретнее заголовок (название, цена, условие); чем дальше, тем больше заголовок говорит о задаче читателя, а не о продукте.
9. **Варианты.** 2–3 варианта с одной строкой, чем каждый отличается и на какой запрос рассчитан. Не 20 «хуков» на выбор.
10. **Проверка** по таблице правил; для refresh — сравнить с текущим title по запросам страницы в GSC/Вебмастере: не выпадают ли из заголовка слова, по которым страница уже получает показы.

## Правила

| Правило | Почему | Как проверить |
|---|---|---|
| Обещание = содержание | кликбейт возвращает человека в выдачу | каждое слово title подтверждается страницей |
| Цифра в заголовке — только из страницы | «7 способов» при пяти на странице — ложь | число совпадает с содержанием |
| Год — только если содержание проверено в этом году | год ради свежести — кликбейт | дата проверки на странице совпадает |
| «Лучший», «топ», «№ 1» — только при методике рейтинга на странице и если проект не запрещает | иначе ничем не подкреплённая оценка | на странице есть методика и дата; запреты в `.papa-seo/project.md` |
| Язык запроса, а не язык компании | человек ищет своими словами | слова title есть в запросах или заголовках выдачи |
| Title, H1, slug, description — об одном | расхождение путает человека и поисковик | одна и та же тема во всех четырёх |
| Без набивки | keyword stuffing — спам-политика (facts-2026 §9) | ключ один раз, без перечня синонимов |
| Регистр по-русски | Title Case в русском — ошибка | заглавная у первого слова и имён собственных |
| Slug не меняют ради года или нового заголовка | смена URL — переезд (`migration.md`) | URL прежний |
| Для коммерческих страниц — цена и условие, если они есть | Яндекс и человек ищут условия (`yandex.md`) | факт в title или description взят со страницы |

## Шаблоны по типу страницы

Это формы, а не формулы: подставлять только то, что есть на странице.

| Тип | Форма title | Пример формы |
|---|---|---|
| Ответ на вопрос | вопрос или его суть + уточнение | «Как вернуть товар без чека: сроки и что сказать продавцу» |
| Инструкция | «Как сделать X» + условие или инструмент | «Как настроить счётчик Метрики на сайте на Тильде» |
| Сравнение | «X или Y» + критерий выбора | «Что выбрать для небольшого интернет-магазина, X или Y» |
| Подборка | что + для кого + сколько (если правда) | «Конструкторы сайтов для фотографа: 8 вариантов с ценами» |
| Категория | название категории + город или главное свойство | «Угловые диваны в Казани» |
| Карточка товара | название модели + главное отличие | «Диван „Модель“ с ящиком для белья, 220 см» |
| Карточка сущности | название + что это + проверка | «Компания: условия, ГЕО, контакты — проверено в октябре 2026» |
| Лендинг / услуга | услуга + для кого + условие | «Бухгалтерия для ИП на УСН — от 3000 ₽ в месяц» |
| Новость | что произошло + что это меняет | «Банк поднял ставку по вкладам до 18 %. Кого это касается» |

Цифры, города, цены и даты в примерах — места подстановки, а не готовые утверждения.

## Чего не делать

- Не писать заголовок, который обещает больше, чем страница даёт.
- Не ставить год, число вариантов, «обновлено», «проверено», если это не правда на странице.
- Не использовать «лучшие / топ / рейтинг» без методики и вопреки запретам проекта.
- Не подгонять title под число символов как под норму; не обрезать смысл ради «60 символов».
- Не плодить десятки вариантов «на выбор»: два-три обоснованных лучше.
- Не менять title страницы с трафиком, не проверив запросы, по которым она уже показывается.

## Выход

- 2–3 варианта title с пояснением, H1, description, первый абзац (или правка текущего).
- Для существующей страницы — таблица «было → стало → почему», и какие запросы из GSC/Вебмастера учтены.
- Предупреждения: обещания, которые не подтверждаются страницей; запреты проекта.
- Строка «Дальше:».
