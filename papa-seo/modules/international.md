# Языковые и региональные версии: hreflang, x-default, canonical

Проверяет, что поисковик понимает, какие страницы — версии одного документа для разных языков или регионов, и показывает нужную: hreflang (HTML, заголовок, sitemap), x-default, согласованность с canonical, перевод основного контента. Правила — facts-2026 §8.

**Когда грузить:** режим `audit`, `fix`; «сделали английскую версию», «в выдаче не та языковая версия», «проверь hreflang», «мультирегиональный сайт».

**Входы:** URL одной версии (лучше — по URL каждой языковой версии для 3–10 пар); sitemap с `xhtml:link` (если hreflang там); карта соответствия версий от пользователя (CSV `ru_url,en_url,…`), если есть.

## Шаги

1. **Найти, где объявлен hreflang.** `python3 scripts/page_facts.py <URL> --out facts.json` (теги `<link rel="alternate" hreflang>` и заголовок `Link`), `python3 scripts/sitemap_check.py <sitemap>` (аннотации `xhtml:link`). Способы равноценны (facts-2026 §8): если используются несколько — проверить, что они не противоречат.
2. **Собрать кластер.** Для страницы — все альтернативы; для каждой альтернативы — получить её набор (последовательно, пауза ≥ 2 с, ≤ 20 URL). Кластер валиден, если наборы совпадают у всех участников.
3. **Проверить каждую пару** по таблице ниже: самоссылка, взаимность, коды, статус и canonical каждой альтернативы, протокол/хост/слэш один в один с canonical.
4. **Основной контент переведён?** Сравнить язык основного текста версий (`page_facts`: первый абзац, H1). Непереведённая «версия» — дубль, а не альтернатива (facts-2026 §8). Переведены только меню и подвал — находка high.
5. **x-default** — нужен, если есть страница выбора языка или автоперенаправление; иначе — по желанию. Проверить, что он ведёт на 200 и не на noindex.
6. **Автоперенаправление по IP/Accept-Language.** Если сервер перенаправляет — проверить, что краулер из любой страны может открыть каждую версию (ссылки на версии в HTML, редирект не 301 на «свою» версию для всех).
7. **Гейт доказательств.** «Нет hreflang» — только после проверки всех трёх способов. «Нет обратной ссылки» — только после получения HTML или sitemap альтернативы, а не по догадке.
8. **Словарь-наложение (одна база, два языка).** Если версии строятся из одного шаблона с переводом строк: убедиться, что URL-пары детерминированы (функция или таблица соответствия), что непереведённые страницы не попадают в кластер, и что canonical каждой версии — на себя, а не на исходный язык.
9. **Яндекс.** Регион сайта у Яндекса задаётся в Вебмастере («Региональность», `references/yandex.md` §8). Как Яндекс обрабатывает hreflang, в пакете не перепроверено: сверять по справке Вебмастера, выводы о Google на Яндекс не переносить.
10. Находки → `templates/finding.schema.json`; исправленный набор тегов или sitemap — черновиком.

## Проверки

| Что | Как проверить | Severity | Движок |
|---|---|---|---|
| Нет самоссылки в наборе | набор страницы содержит её собственный URL | high | google |
| Нет взаимной ссылки (A → B, B ↛ A) | наборы всех альтернатив | high | both |
| Неверный код языка (`eng`, `ua` вместо `uk`) или региона (`en-UK` вместо `en-GB`), только регион | ISO 639-1 / ISO 3166-1 Alpha-2 (facts-2026 §8) | high | both |
| Неподдерживаемые коды вроде `es-419` | facts-2026 §8 | medium | google |
| Альтернатива отдаёт 3xx/4xx/5xx или noindex | `http_safe.py fetch` каждой | high | both |
| hreflang указывает на неканонический URL (canonical альтернативы ≠ её URL) | canonical из `page_facts` альтернативы | high | google |
| Canonical версии ведёт на другой язык | canonical против `hreflang` | high | both |
| Протокол, хост, слэш в hreflang не совпадают с canonical | строковое сравнение | medium | both |
| Основной контент не переведён | язык первого абзаца и H1 | high | both |
| Переведены только навигация и подвал | доля текста на языке версии | medium | both |
| Несколько способов объявления противоречат друг другу | HTML против sitemap против заголовка | medium | google |
| x-default отсутствует при странице выбора языка/автоперенаправлении | наличие и цель | low | google |
| x-default ведёт на 404/noindex | `http_safe.py` | medium | google |
| Автоперенаправление по IP без видимых ссылок на другие версии | HTML-ссылки, поведение редиректа | high | both |
| `lang` у `<html>` не совпадает с языком версии | `page_facts` (Google язык по `lang` не определяет, но это ошибка доступности) | low | both |
| Title/description не переведены | язык меты против текста | medium | both |
| В sitemap-кластере дубли URL или неполные группы | `sitemap_check.py` | medium | google |

## Чего не делать

- Не советовать «перенести hreflang в sitemap как лучший способ» — способы равноценны.
- Не считать hreflang способом склеить непереведённые дубли.
- Не ставить canonical всех версий на «главный» язык.
- Не настраивать автоперенаправление, которое не пускает краулер к другим версиям.
- Не выдумывать коды для «региона СНГ» и подобных: есть только язык и страна по ISO.
- Не обходить все версии всех страниц сайта: выборка пар, остальное — по sitemap или CSV.

## Выход

Находки по `templates/finding.schema.json`, `module: "international"`. Плюс матрица кластера: URL × язык-регион × самоссылка × взаимность × статус × canonical × язык контента; черновик исправленного набора тегов или фрагмента sitemap.
