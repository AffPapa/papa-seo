# Русский слой редактуры

Справочник для `deai.md`, `edit.md`, `write.md`, `landing.md`, `headlines.md`. Здесь то, что в английских правилах де-AI не работает или работает наоборот. Словарь штампов совпадает с тем, что ищет `scripts/deai_scan.py`; новые записи добавлять в оба места.

Главный принцип всех разделов: **снимать, а не дописывать.** Штамп убирают удалением оболочки или перестройкой фразы из тех же слов. Живость, мнение, пример, частица, которых нет у автора, в текст не добавляются.

## 1. Регистр решает, что снимать

Перед правкой назвать регистр текста. Канцелярит в юридическом договоре — норма жанра, в посте — помеха.

| Регистр | Что править | Что не трогать | `--genre` для `deai_scan.py` |
|---|---|---|---|
| Маркетинг, лендинг, пост, блог | всё из §3–§6 | цитаты, названия, реквизиты | `marketing` |
| Экспертная статья, обзор | §3–§5, §6 по кластеру | термины, цитаты | `expert` |
| Деловое письмо | §3 (пустые зачины, подводки), §4 частично | формальное обращение, «в связи с» | `business` |
| Документация | канцелярит и пассив, если смысл не меняется | версии, команды, код, названия полей | `docs` |
| Новости, энциклопедия | остатки чат-бота, грубые ошибки | канцелярит и кальки в норме жанра | `news` |
| Научный текст | остатки чат-бота, грубые ошибки | связки, пассив, «является», формульные выводы | `academic` |
| Юридический текст | только фактические ошибки | всё остальное | `legal` |
| Художественный текст | остатки чат-бота в авторской речи | реплики героев, ритм и повторы автора | `fiction` |

В любом регистре не трогать: код, таблицы данных, URL, реквизиты, команды, цитаты, фрагменты с юридической силой. Текст короче 50 слов проверять только на остатки чат-бота и пустые зачины.

## 2. Действия редактора

Для каждого мешающего места выбрать одно действие. Это рабочая разметка, не отчёт.

| Действие | Что делает | Пример |
|---|---|---|
| оставить | место не мешает читателю | терминологическое «является» в определении |
| снять оболочку | убрать подводку, утверждение остаётся | «Стоит отметить, что доставка бесплатная» → «Доставка бесплатная» |
| заменить | та же мысль проще | «осуществляем доставку» → «доставляем» |
| склеить | убрать повтор соседних фраз | два предложения про один срок → одно |
| разбить | одна мысль — одно предложение | простыня на 40 слов с тремя «который» → два предложения |

Если предложение без правки встало бы в текст любой другой компании про любой другой товар, оно ничего не сообщает. Есть в нём факт — оставить факт. Нет — удалить целиком.

## 3. Пустые зачины, подводки, формульные концовки

| Штамп | Что вместо |
|---|---|
| «В современном мире…», «В наше время…», «В эпоху цифровизации…» | начать с факта из текста |
| «В условиях растущей конкуренции…» | начать с факта; если конкуренция важна — цифра с источником |
| «Стоит отметить, что…», «Важно понимать, что…», «Следует подчеркнуть…» | убрать подводку |
| «Давайте разберёмся», «Погрузимся в тему», «Рассмотрим подробнее» | сразу к сути |
| «Ни для кого не секрет, что…», «Не секрет, что…» | удалить |
| «Подводя итог», «В заключение», «Таким образом,» в начале вывода | закончить, когда кончилось содержание; «устроен таким образом» — не штамп |
| «Можно с уверенностью сказать» | сказать без преамбулы |
| «На сегодняшний день» | «сейчас» или дата |

## 4. Раздувание значимости и рекламные клише

| Штамп | Что вместо |
|---|---|
| «играет ключевую / важную / решающую роль» | что именно делает, если это есть в тексте |
| «является неотъемлемой частью» | назвать связь или удалить |
| «раскрыть потенциал», «вывести на новый уровень», «открывает новые горизонты» | конкретный результат из текста; нет его — удалить |
| «комплексный подход / решение» | перечислить, что входит |
| «индивидуальный подход» | в чём он: замер, расчёт, отдельный менеджер — если это правда |
| «высококвалифицированные специалисты» | стаж, допуск, сертификат — фактом; нет — удалить |
| «в кратчайшие сроки» | срок цифрой |
| «широкий ассортимент / спектр» | сколько позиций или каких |
| «уникальный», «инновационный», «передовой», «революционный» + существительное | чем отличается, с доказательством |
| «идеальное решение», «настоящий прорыв», «залог успеха», «гармоничное сочетание» | удалить оценку без основания |
| «лидер рынка», «№ 1» | источник рейтинга с датой или удалить |
| «мы рады предложить» | сразу предложение |
| «успейте!» без срока | дата окончания или число мест — это факт и остаётся; без них удалить |

## 5. Канцелярит и размытые авторитеты

| Конструкция | Что вместо |
|---|---|
| «данный / данная / данное» | «этот / эта / это»; «данные» в значении «сведения» — обычное слово |
| «осуществлять», «производить», «проводить» + отглагольное («осуществление установки») | глагол действия: «устанавливаем» |
| «в рамках», «в целях», «посредством» | предлог или перестройка: «для», «чтобы», «через» |
| «является» через предложение | перестроить; в определениях и науке оставить |
| канцелярский пассив («оплата производится», «не предоставляется») | кто что делает: «вы платите», «мы не даём» |
| «в связи с этим» | показать связь словами текста; в деловом письме допустимо |
| «эксперты считают», «исследования показывают», «многие компании» | назвать источник и год или убрать |
| «всё больше и больше» | цифра с источником или удалить |

## 6. Кальки с английского

Признак перевода, а не обязательно машины. Снимать там, где в русском есть обычное слово.

| Калька | По-русски |
|---|---|
| «играть роль» в каждом абзаце | «влиять на», «отвечать за», конкретный глагол |
| «на ежедневной основе» | «каждый день» |
| «адресовать проблему» | «решать», «заниматься» |
| «в конце дня» (at the end of the day) | «в итоге» или удалить |
| «это имеет смысл» (makes sense) в значении «логично» | «логично», «разумно» |
| «решение» вместо названия продукта | назвать продукт |
| «довольно / достаточно» перед каждым прилагательным | удалить усилитель |
| «Не только X, но и Y» с пустым X | прямое утверждение; если X и Y разные факты — оставить |
| «Это не просто X, а Y», «Это не X — это Y» | сказать одно; содержательное противопоставление оставить |
| притяжательные «ваш / свой» в каждой фразе («ваш бизнес», «ваши клиенты») | убрать лишние |
| Title Case («Как Выбрать Диван») | в русском заглавная у первого слова и имён собственных |
| двоеточие-подзаголовок в каждом заголовке («Доставка: как это работает») | обычная фраза |

## 7. Тире

Длинное тире — штатный знак русской пунктуации. Правило «ноль тире» из англоязычных скилов по-русски даёт ошибки, а замена тире дефисом — типографская ошибка.

**Тире нужно (не трогать):**
- между подлежащим и сказуемым-существительным без связки: «Москва — столица»;
- перед «это», «вот», «значит», «это значит» в сказуемом: «Главное — это срок»;
- на месте пропущенного члена: «Одним — скидки, другим — подарки»;
- в бессоюзном сложном предложении со следствием, резким противопоставлением или быстрой сменой событий;
- перед обобщающим словом после перечня, при обособленном приложении в конце, при вводной конструкции посреди фразы;
- в диапазонах чисел — без пробелов: «5–7 дней», «2025–2026».

**Тире как признак (только в кластере):**
- тире-драматизм перед эффектной концовкой, в каждом абзаце: «И тогда пришло понимание — всё было зря»;
- тире вместо запятой или двоеточия по всему тексту;
- определение через тире в начале каждого раздела по одной схеме.

Одиночное тире не повод для правки. Если тире-драматизм повторяется, фразу перестраивают (точка, двоеточие, порядок слов), а грамматическое тире оставляют. `deai_scan.py` считает только плотность тире и ничего не правит.

## 8. Кавычки и типографика

- Кавычки — «ёлочки», внутри — „лапки“. Сами «ёлочки» не признак машины; признак небрежности — смешение «ёлочек» и "прямых" в одном тексте.
- Десятичная запятая: 12,5 %. Знак процента — единообразно по стайлгайду проекта (с неразрывным пробелом или без).
- Разряды: числа от пяти цифр делятся неразрывным пробелом (10 000, 1 250 000); четырёхзначные обычно не делят (5000), кроме колонок таблиц.
- Неразрывный пробел: между числом и единицей (15 кг, 1990 ₽), в инициалах (А. С. Пушкин), в «т. е.», «т. д.».
- Сокращения: «тыс.», «млн», «млрд» (после «млн» и «млрд» точки нет), «руб.» или «₽» — одно на текст.
- Даты: «12 марта 2026 г.» или «12.03.2026» — один формат на текст.
- Буква «ё» — как решено в проекте, но одинаково по всему тексту; в именах и там, где без неё путаница («всё / все»), — ставить.
- Многоточие — один символ «…» или три точки, единообразно.

## 9. Факт-замок

Действует поверх любого правила этого файла. При правке без искажений переносятся:

- числа вместе с единицами, выборкой, периодом и предметом сравнения;
- даты, сроки, цены, проценты, названия, имена, реквизиты, ссылки;
- оговорки при фактах: «около», «примерно», «до 5000», «от 3 дней», «не более», «обычно», «часто», «как правило», «может», «возможно», «только», «лишь», «если», «при условии», «по данным», «ожидаем», «планируем», «один из», «риск»;
- полнота и область действия: «все заявки за май» не становится «все заявки»;
- причинность и порядок: два факта рядом не становятся причиной и следствием;
- модальность: намерение не становится свершившимся фактом.

Снимается только оговорка мнения («может показаться», «в некотором смысле»), а не оговорка точности.

Сдвиги, которые при сокращении случаются чаще всего:

| Было | Нельзя | Почему |
|---|---|---|
| «риск переделок» | «придётся переделывать» | возможность стала неизбежностью |
| «один из ключевых» | «главный» | усилено |
| «обычно за 2 дня» | «за 2 дня» | исчезла оговорка частоты |
| «до 30 % экономии» | «30 % экономии» | верхняя граница стала обещанием |
| «планируем запустить в мае» | «запускаем в мае» | план стал фактом |
| «если заказ до 14:00» | «заказ доставим сегодня» | условие пропало |
| «по данным опроса 200 клиентов» | «клиенты считают» | выборка и источник пропали |

Проверка — `python3 scripts/factdiff.py до.md после.md`: пропавшие числа, даты, имена и оговорки. Числа словами и смысловые сдвиги из таблицы выше скрипт не видит, их сверяет человек.

## 10. Не маркеры

Не помечать и не «исправлять»:

| Не признак | Почему |
|---|---|
| грамотность, чистая пунктуация, ровный формальный тон в формальном жанре | так пишут и люди; вставлять ошибки нельзя |
| одиночное тире, одиночное «является», одиночное слово из словаря | считаются только кластеры |
| грамматическое тире (§7) | норма языка |
| «ёлочки» | норма русской типографики |
| риторический вопрос, общее «не X, а Y» с разными X и Y | обычные приёмы живой речи |
| осмысленная тройка («пришёл, увидел, победил»), намеренный повтор (анафора) | работают на смысл |
| длинное предложение в научном или юридическом тексте | жанровая норма |
| ровный текст неносителя языка или автора с особым стилем | не доказательство машины |
| привычка автора, подтверждённая его образцами | редактируем к его голосу (`voice.md`) |

## 11. Вернуть русский регистр, не добавляя

Модели тянут русский текст к существительным и пассиву. Возвращать разговорную норму можно только перестройкой того, что уже написано:

- глагол вместо отглагольного существительного: «проведение проверки» → «проверяем»;
- «это» вместо «данный», «потому что» и «поэтому» вместо цепочки «в связи с тем, что»;
- деепричастный хвост, который повторяет главное, — отдельным предложением или удалить;
- порядок слов «известное → новое»: новое в конец фразы;
- одно «однако» на абзац вместо трёх; связки «кроме того», «более того», «при этом» подряд — снять лишние;
- серию предложений одной длины ломать перестановкой: разбить одно длинное, слить два коротких, удалить придаточное. Слова ради ритма не добавлять.

Частицы («ну», «вот», «вообще»), вопросы к читателю, шутки и сравнения, которых нет у автора, не вставлять.

## 12. Английский текст

Английский словарь штампов и проверки (артефакты чат-бота, «delve», «it's worth noting», «not only… but also») — в `deai_scan.py` и `deai.md`. Английские нормы (сокращения don't/it's, Title Case в заголовках по стайлгайду издания) к русскому не переносить, русские (§7–§8) — к английскому.
