# Чек-лист запуска нового сайта

Шаблон для шага 9 `modules/newsite.md`. В файл проекта (`07-launch-checklist.md`) переносить только пункты, которые применимы к движку и бизнесу пользователя. Как это делается в конкретном конструкторе — `references/site-builders.md`; чего там нет, пишем «проверить в справке конструктора», пункты меню не придумываем.

У каждого пункта есть способ проверки и источник. Ориентир пакета без требования поисковика помечен «ориентир пакета».

## Источники (проверено 17.11.2026)

Google Search Central и справка Search Console:
- [G1] developers.google.com/search/docs/essentials/technical — минимум для индексации: Googlebot не заблокирован, страница отдаёт 200, на ней есть индексируемое содержимое; индексация при этом не гарантирована.
- [G2] support.google.com/webmasters/answer/9008080 — подтверждение прав: HTML-файл, HTML-тег, Google Analytics, Tag Manager, DNS-запись; ресурс «Домен» — только DNS; права держатся, пока токен на месте.
- [G3] developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap — sitemap отправляют в Search Console или строкой `Sitemap:` в robots.txt; отправка — «merely a hint».
- facts-2026 §1, §2, §3, §4, §12 — robots.txt, noindex, редиректы и canonical, лимиты sitemap, карточка компании.

Яндекс Справка (Вебмастер), `yandex.ru/support/webmaster/ru/…`:
- [Y1] …/service/quick-start — сайт добавляют с тем протоколом и www, с которыми он будет в поиске; только собственный домен; сервер должен отвечать роботу 200; главная с редиректом на `/index.html` мешает загрузке; добавление не гарантирует показ в поиске.
- [Y2] …/yandex-indexing/site-addresses — роботы сначала индексируют все адреса сайта (www, без www, http, https) как отдельные сайты и со временем склеивают; главный адрес можно указать в Вебмастере, иначе робот выберет сам.
- [Y3] …/indexing-options/sitemap — sitemap указывают в Вебмастере или директивой в robots.txt; робот загружает файл в течение двух недель; статусы «OK», «Ошибка», «Редирект», «Не проиндексирован».
- [Y4] …/site-geography/site-region — регион задают в Вебмастере или через Яндекс Бизнес; модератор сверяет его с сайтом: контакты на видном месте, сайт доступен и не заражён.
- [Y5] …/robot-workings/site-reindex — «Переобход страниц» с дневным лимитом; robots.txt робот перечитывает сам за несколько часов; sitemap на переобход не отправляют.
- [Y6] …/adding-site/indexing-prohibition — закрыть от индекса можно `Disallow`, метатегом `noindex` или авторизацией; для главной Яндекс советует авторизацию.

## До запуска

| Пункт | Как проверить | Источник |
|---|---|---|
| Стенд закрыт от индекса паролем; если пароля нет — `noindex` на всех страницах. `Disallow: /` в robots.txt без пароля не прячет: URL может попасть в индекс без текста | открыть стенд в окне без входа; `audit.py <адрес стенда> --brief` — блок «блокирует индексацию» | Y6; facts-2026 §1, §2 |
| Домен куплен, в черновиках `site.example` заменён на него (robots.txt, sitemap.xml, llms.txt, JSON-LD, `page_map.csv`, `links.csv`) | поиск `site.example` по папке проекта | — |
| Выбран один главный адрес: https, с www или без | записан в `project.md` | Y1, Y2 |
| Адреса страниц окончательные. Смена адреса после запуска — это уже переезд (`modules/migration.md`) | `pages.txt` совпадает с адресами в конструкторе | facts-2026 §3 |
| Каждая будущая индексируемая страница отдаёт 200 и несёт текст в HTML, а не только картинкой | сохранить HTML страницы, `audit.py <файл> --base-url https://<домен>/<путь> --brief` | G1 |
| Главная отвечает 200 сама, без редиректа на `/index.html` или `/home` | `audit.py <файл главной> --base-url https://<домен>/ --brief` или после запуска `audit.py https://<домен>/ --brief` | Y1 |
| У каждой страницы свой title и canonical на себя | тот же отчёт `audit.py`, группы `meta` и `access` | facts-2026 §3, §5 |
| Название, адрес, телефон, часы одинаковы на сайте и в будущих карточках; телефон и адрес текстом | `page_facts.py <файл контактов>`; таблица NAP из `modules/local.md` | Y4; facts-2026 §12 |
| Контакты на видном месте — без этого регион в Вебмастере не пройдёт модерацию | первый экран контактов и подвал | Y4 |
| Все `[NEED: …]` закрыты, или страница с ними не публикуется | поиск `[NEED` по черновикам и HTML | — |
| JSON-LD собран из данных пользователя и проверен | `schema_check.py <файл>` по каждому файлу из `schema/` | `modules/schema.md` |
| robots.txt и sitemap.xml проверены (свои черновики или файлы конструктора) | `robots_check.py robots.txt --status 200`; `sitemap_check.py sitemap.xml` | facts-2026 §1, §4 |
| YMYL-ниша: лицензии, обязательные предупреждения, политика персональных данных — по документам заказчика; какие формулировки требует закон, уточнить у юриста | список документов в `README.md` проекта | `modules/newsite.md`, раздел YMYL |

## День запуска

| Пункт | Как проверить | Источник |
|---|---|---|
| Снят запрет со стенда: нет `Disallow: /` для поисковых роботов, нет `noindex`, нет пароля. В WordPress снята галочка «Discourage search engines…» (`references/site-builders.md`) | `audit.py https://<домен>/ --brief` — блок «блокирует индексацию» пуст | G1; facts-2026 §2 |
| Остальные варианты адреса (http, www или без) отдают 301 на главный | `audit.py https://<домен>/ --brief --host-variants` (плюс два запроса: http и www-вариант главной) | Y2; facts-2026 §3 |
| `https://<домен>/robots.txt` отдаёт 200 и не закрывает Googlebot и YandexBot | `robots_check.py https://<домен>/robots.txt` | facts-2026 §1 |
| `https://<домен>/sitemap.xml` отдаёт 200, в нём только индексируемые адреса главного хоста, строка `Sitemap:` есть в robots.txt | `sitemap_check.py https://<домен>/sitemap.xml` | G3, Y3 |
| Сайт добавлен в Яндекс Вебмастер с главным адресом, права подтверждены | раздел «Права доступа» в Вебмастере | Y1 |
| Сайт добавлен в Search Console, права подтверждены; токен (файл, тег, DNS-запись) не удаляется после подтверждения | отчёт о правах в Search Console | G2 |
| sitemap отправлен в Вебмастер и Search Console | статус файла в обоих кабинетах | G3, Y3 |
| В Вебмастере указан регион, если сайт про услуги или товары в городе | «Представление в поиске» → «Региональность» | Y4 |
| Счётчик Метрики или GA4 стоит на всех страницах — иначе через месяц не с чем сравнивать (ориентир пакета) | исходный код двух-трёх страниц | `modules/measure.md` |

| Пункт | Как проверить | Источник |
