# Быстрый старт

Четыре шага: поставить, проверить страницу, проверить сайт, прочитать отчёт. Ниже — две задачи с текстами. Примеры для агента пишутся в чат как есть.

## 1. Поставить

Скопируйте промпт из [README](README.md#установить-одним-промптом) и отдайте агенту с доступом к файлам (Claude Code, Codex, Cursor и другие). Он положит папку `papa-seo/` в каталог скилов и проверит её. Руками — скопировать папку `papa-seo/` в `~/.claude/skills/` (Claude Code) или `~/.agents/skills/` (Codex и другие). Нужен Python 3.10 или новее, сторонних пакетов нет.

Для своего проекта стоит завести `.papa-seo/project.md` из заготовки `papa-seo/templates/project-context.md`; промпт «В свой проект» из README делает это сам и задаёт пять вопросов. Без файла скил не знает рынок и держится самых осторожных настроек.

## 2. Проверить страницу

Агенту в чат:

```
проверь страницу https://example.ru/uslugi/remont-kvartir/
Ключи: ремонт квартир, ремонт под ключ. Рынок — Москва, важен Яндекс.
```

Или сами, из папки скила:

```
python3 scripts/audit.py https://example.ru/uslugi/remont-kvartir/ \
  --keys "ремонт квартир; ремонт под ключ" --out otchet.html
```

Два запроса к сайту: сама страница и `robots.txt`. Дальше всё считается локально: HTML разбирается, текст меряется, доступ ботов сверяется с RFC 9309 и правилами Яндекса. Проверки берутся из `papa-seo/references/registry.json`: 415 параметров в тринадцати группах, у каждого записано, из чего он считается и есть ли требование в документации поисковика.

Получите сводку в терминале (счёт по статусам и первые пункты к починке), `otchet.html` (таблицы по группам, открывается без интернета, печатается) и, если нужно сравнивать выпуски, `--json otchet.json`.

Страница ещё не опубликована — дайте файл: `python3 scripts/audit.py ./build/remont.html --base-url https://example.ru/uslugi/remont-kvartir/`. Свой список до двадцати адресов — `--pages list.txt`, с паузой ≥ 2 секунды и проверками по сайту (дубли title и description, закрытые от индексации страницы).

## 3. Проверить весь сайт

```bash
python3 scripts/audit.py --site https://example.ru --out otchet.html
```

Скрипт находит карту сайта (`sitemap.xml` в корне или из `robots.txt`, понимает sitemap-index) и берёт выборку ~25 адресов: главная обязательно, дальше поровну по типам путей. Ходит по одному с паузой ≥ 2 секунды, закрытое в `robots.txt` не запрашивает. Размер выборки — `--limit N`, до 100; выше 30 скрипт предупредит о нагрузке. Карты нет — возьмёт ссылки с главной.

Агенту то же самое одной фразой: «проверь весь сайт https://example.ru и собери один список, что чинить первым». Полный промпт — в README, раздел «Весь сайт одной командой».

## 4. Прочитать отчёт

- Карточки сверху: сколько проблем, предупреждений, строк в норме, без данных и непроверенных, и сколько параметров из 415 проверено. При `--site` ниже строка охвата: сколько страниц проверено из скольких в карте сайта.
- Вердикт — одна-две фразы: есть ли блокирующее (noindex, ответ не 200, закрытый поисковый бот) и сколько требований поисковиков не выполнено. Под ним свёрнута справка «Как читать этот отчёт».
- «Чинить первым»: блокирующее сверху, потом требования поисковиков, потом советы редактора. Внутри — тяжесть, умноженная на число страниц с находкой, так что ошибка шаблона на многих страницах обгоняет единичную, даже более серьёзную. Следом «Повторяется по сайту»: находка, число страниц, адреса-примеры.
- «Факт» посчитан из HTML, заголовков или `robots.txt`; «оценка» — эвристика. «Ориентир редактора» — требования поисковика нет, это наш совет; таких параметров в реестре 77, сколько проверено в этом запуске — сказано в отчёте.
- «Не проверяли» не значит «в порядке». Причина — в справке: проверки нет в скрипте, нужен обход или нужен браузер и выгрузка.
- Если проверялась одна страница и она ответила не 2xx, отчёт всё равно будет, а код выхода — 2. Это для CI.

Сводного балла «SEO 87 из 100» нет: его пришлось бы складывать из весов, которых никто не публиковал.

## Дальше: статья по ТЗ

Если ТЗ уже есть:

```
papa-seo write по ТЗ из ./briefs/kak-vybrat-laminat.md
Источники: ./sources/ (паспорта производителей, наш прайс).
```

Если ТЗ нет, сначала:

```
papa-seo brief «как выбрать ламинат для кухни»
```

Скил смотрит выдачу встроенным веб-поиском, определяет интент и тип страницы и собирает ТЗ по шаблону `templates/brief.md`: угол, структура, вопросы эксперту, список того, что нельзя писать без источника. ТЗ стоит прочитать и поправить до текста.

Дальше `write` пишет черновик. Ответ на главный вопрос стоит в начале. Каждая цифра, дата и цена берётся из ваших источников со ссылкой, а если источника нет, в тексте остаётся пометка `[NEED: …]`. Голос текста задаёт `templates/voice-profile.md`, если вы его заполнили. После черновика идут `factcheck` (таблица «утверждение → источник → статус») и `deai`, правка штампов без «добавления души».

Результат — Markdown-файл в папке, которую вы назвали или которая указана в `.papa-seo/project.md`. На сайт скил ничего не выкладывает.

## Дальше: обновить старую страницу

```
papa-seo refresh https://example.ru/blog/laminat-2023/
Выгрузка Search Console за 16 месяцев: ./gsc/laminat.csv
```

Что происходит:

1. Скил сравнивает периоды по вашей выгрузке: какие запросы просели, какие близко к топу. Без выгрузки этот шаг пропускается, о чём будет написано в отчёте.
2. Смотрит текущую выдачу по главным запросам и сравнивает тип страниц в топе с вашей.
3. Отмечает устаревшее: годы, цены, ссылки на исчезнувшие источники, факты, которые изменились.
4. Готовит правленую версию. `factdiff.py` сравнивает до и после и показывает, какие числа, даты, ссылки и имена пропали или появились, чтобы при переписывании ничего не потерялось молча.

Результат — новая версия текста, список изменений и что проверить в Search Console через несколько недель. Опубликовать или нет, решаете вы.

## Если что-то пошло не так

- Агент ответил без находок с доказательствами — попросите показать `evidence` для каждой. Находка без фрагмента-доказательства считается гипотезой.
- Агент просит ключ платного API — он не обязателен, базовый режим работает без него.
- Сайт отдаёт ошибку или стоит за защитой от ботов — скил не обходит такую защиту. Сохраните страницу из браузера и дайте файл.
