# Быстрый старт

Три задачи, с которых обычно начинают. Скил уже стоит в папке скилов: промптом из [README](README.md#установить-одним-промптом) или копированием папки `papa-seo/` руками. Примеры ниже пишутся агенту в чат как есть.

Перед первой задачей на своём проекте стоит завести `.papa-seo/project.md` из заготовки `papa-seo/templates/project-context.md`; промпт «В свой проект» из README делает это сам и задаёт пять вопросов. Без файла скил не знает рынок и работает с самыми осторожными настройками.

## 1. Проверить страницу

```
papa-seo page https://example.ru/uslugi/remont-kvartir/
Рынок — Москва, важен Яндекс.
```

Что происходит:

1. Агент один раз скачивает страницу через `http_safe.py` и сохраняет цепочку редиректов и заголовки ответа.
2. `page_facts.py` достаёт из HTML title, meta robots, canonical, hreflang, заголовки, ссылки, изображения и JSON-LD. Отдельно отмечает, сколько текста есть в сыром HTML: если почти нет, страница, скорее всего, собирается скриптом в браузере.
3. `robots_check.py` проверяет, открыт ли адрес для Googlebot, Яндекса и AI-ботов, включая YandexAdditional.
4. Модули `on-page`, `tech-audit` и `schema` разбирают факты. Если вы назвали Яндекс, подключается и его дорожка.

Что получите: короткий список находок по схеме `finding.schema.json`, у каждой есть фрагмент-доказательство, статус и способ проверить правку. Сначала идут блокирующие проблемы (noindex, 5xx, закрытый робот), потом остальное.

Чего не будет: обхода остального сайта, частотности запросов без источника, совета «добавьте разметку», если она на странице уже есть.

Если страница ещё не опубликована, дайте файл: `papa-seo page ./build/remont.html`.

## 2. Написать статью по ТЗ

Если ТЗ уже есть:

```
papa-seo write по ТЗ из ./briefs/kak-vybrat-laminat.md
Источники: ./sources/ (паспорта производителей, наш прайс).
```

Если ТЗ нет, сначала:

```
papa-seo brief «как выбрать ламинат для кухни»
```

Скил смотрит выдачу встроенным веб-поиском, определяет интент и тип страницы и собирает ТЗ по шаблону `templates/brief.md`: угол, структура, вопросы эксперту, список того, что нельзя писать без источника. ТЗ стоит прочитать и поправить до текста.

Дальше `write` пишет черновик. Ответ на главный вопрос стоит в начале. Каждая цифра, дата и цена берётся из ваших источников со ссылкой, а если источника нет, в тексте остаётся пометка `[NEED: …]`. Голос текста задаёт `templates/voice-profile.md`, если вы его заполнили. После черновика идут `factcheck` (таблица «утверждение → источник → статус») и `deai`, правка штампов без «добавления души».

Результат — Markdown-файл в папке, которую вы назвали или которая указана в `.papa-seo/project.md`. На сайт скил ничего не выкладывает.

## 3. Обновить старую страницу

```
papa-seo refresh https://example.ru/blog/laminat-2023/
Выгрузка Search Console за 16 месяцев: ./gsc/laminat.csv
```

Что происходит:

1. Скил сравнивает периоды по вашей выгрузке: какие запросы просели, какие близко к топу. Без выгрузки этот шаг пропускается, о чём будет написано в отчёте.
2. Смотрит текущую выдачу по главным запросам и сравнивает тип страниц в топе с вашей.
3. Отмечает устаревшее: годы, цены, ссылки на исчезнувшие источники, факты, которые изменились.
4. Готовит правленую версию. `factdiff.py` сравнивает до и после и показывает, какие числа, даты, ссылки и имена пропали или появились, чтобы при переписывании ничего не потерялось молча.

Результат — новая версия текста, список изменений и что проверить в Search Console через несколько недель. Опубликовать или нет, решаете вы.

## Если что-то пошло не так

- Агент ответил без находок с доказательствами — попросите показать `evidence` для каждой. Находка без фрагмента-доказательства считается гипотезой.
- Агент просит ключ платного API — он не обязателен, базовый режим работает без него.
- Сайт отдаёт ошибку или стоит за защитой от ботов — скил не обходит такую защиту. Сохраните страницу из браузера и дайте файл.
