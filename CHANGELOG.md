## [0.1.0] — 2026-10-24

Первая публичная версия.

### Добавлено

- Скил `papa-seo`: роутер `SKILL.md` и режимы `audit`, `page`, `plan`, `brief`, `write`, `refresh`, `edit`, `links`, `fix`, `measure`, `geo`, `yandex`.
- Политики: безопасность (чужой контент — данные, SSRF, секреты), правила доказательств, лестница полномочий без автопубликации.
- Модули по функциям: технический аудит, индексация, on-page, разметка, скорость, AI-поиск, Яндекс, E-E-A-T, семантика, выдача, внутренние и внешние ссылки, локальное SEO, магазины, hreflang, шаблонные страницы, миграции, логи, измерения, ТЗ, написание, правка, де-AI, заголовки, лендинги, голос, фактчекинг, метрики текста, отчёт.
- Справочники: датированные факты со ссылками на первоисточники, список мифов, ростер ботов с Яндексом, Яндекс-дорожка, типы страниц, русский стиль.
- Шаблоны: `finding.schema.json`, `brief.md`, `report.md`, `project-context.md`, `voice-profile.md`.
- Скрипты на стандартной библиотеке Python: `http_safe.py`, `page_facts.py`, `robots_check.py`, `sitemap_check.py`, `link_graph.py`, `bot_verify.py`, `text_metrics.py`, `deai_scan.py`, `factdiff.py`, и тесты к ним с набором атак.
- `evals/`: сайт-фикстура с заложенными дефектами, ловушками и prompt-инъекцией, ключ ответов, порядок сравнения «модель без скила / со скилом».
- `LICENSE` (MIT), `THIRD_PARTY_NOTICES.md`, `licenses/`, `source.lock.json`.

### Известные ограничения

- Нет рендера JavaScript: проверяется сырой HTML; признаки CSR помечаются, отрендеренный DOM не сравнивается.
- Строки User-Agent для `http_safe.py fetch --ua-of` во встроенной таблице не сверены с документацией вендоров; перед проверкой WAF сверить вручную.
- Скрытый текст распознаётся по inline-стилям и известным классам, внешний CSS не учитывается.
- `bot_verify.py` проверяет rDNS только для Googlebot, YandexBot и Bingbot; AI-боты помечаются `needs_ip_ranges`.
- `evals/` подготовлены, но сравнение «без скила / со скилом» на моделях ещё не прогонялось.
- Антивирус и сторонний SAST по пакету не запускались; проверка — тесты, ревью кода и поиск опасных конструкций (см. SECURITY.md).
