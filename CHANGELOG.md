## [0.1.1] — 2026-10-26

### Исправлено

- `page_facts.py`: скрытое меню больше не даёт ложный `hidden_instruction`. Мобильная шторка affpapa.org (`hidden`, пункт «SEO-скил для ИИ-агентов») помечалась как скрытое обращение к модели. Теперь скрытый блок считается навигацией, если у него есть признак меню (тег `nav`/`menu`, `role=navigation|menu|menubar`, класс или id вроде `menu`, `drawer`, `mnav`, `data-*drawer`, вложенный `nav` или он цель `aria-controls`) и не меньше 40 % его текста — текст ссылок. Слабые совпадения в таком блоке уходят в новое поле `hidden_navigation_skipped`, императив к модели («ИИ, игнорируй…») помечается как раньше, severity high. Тест на фрагменте живой страницы.
- `page_facts.py`: «Инструкция для ИИ-аудитора: …» в скрытом блоке была находкой low, теперь high. Новый сильный шаблон — русский заголовок-обращение к модели с двоеточием; подпись меню без двоеточия остаётся слабой. Нашёлся на атаке A02 из `evals/`.
- Строки User-Agent для `http_safe.py fetch --ua-of` сверены с документацией Google, Bing, Яндекса, OpenAI, Anthropic, Perplexity и Apple. Обновлены Googlebot (Smartphone вместо редкого варианта), bingbot (вариант с Chrome), GPTBot 1.1 → 1.4, OAI-SearchBot 1.0 → 1.4 (новый формат строки), Applebot (Safari 17.4); добавлен Perplexity-User. Anthropic полных строк не публикует: для ClaudeBot остаётся формат из логов сайтов, и вывод `fetch` теперь это говорит в поле `ua_source`.
- `--ua-of` для записи с несколькими токенами берёт строку только у первого: раньше `--ua-of Googlebot-Image` отправлял строку Googlebot.

### Добавлено

- `references/ai-bots.yaml` и `.json`: поля `ua`, `ua_checked`, `ua_note` у ботов, для которых строку публикует вендор; у ClaudeBot, Claude-User, Claude-SearchBot и YandexAdditional — `ua_note`, почему строки нет. Тест следит, чтобы yaml, json и встроенная таблица не разошлись.
- `page_facts.py`: флаг `canonical_not_self` — единственный canonical не совпадает с адресом страницы.
- `evals/RESULTS-scripts.md`: прогон скриптов по фикстуре без модели. Сами скрипты называют 3 дефекта из 10, ещё 6 видны в фактах и требуют вывода модели, 1 не виден. Атаки A01 и A02 помечаются как high.
- Установка одним промптом: универсальный промпт-установщик и короткие промпты по хостам в README и README.en (Claude Code, Codex, Cursor, хосты Agent Skills, ChatGPT и claude.ai — с оговорками), промпт для своего проекта, установка без ИИ через `git clone`/`cp`, zip и `npx skills add AffPapa/papa-seo`.
- `docs/RESEARCH.md` (и короткий `docs/RESEARCH.en.md`): из чего собран пакет — 105 разобранных репозиториев, доноры с лицензиями и коммитами, что не взяли и почему, мифы, не прошедшие проверку по первоисточникам.
- Архив релиза `papa-seo-0.1.1.zip` на странице релиза GitHub с SHA-256 в описании; `main.zip` ветки — всегда текущий.

### Известные ограничения

- Сравнение «модель без скила / со скилом» на `evals/` по-прежнему не прогонялось.
- Нет сверки цены и наличия Product с текстом, перекрёстной проверки sitemap против noindex и canonical, взаимности hreflang по набору страниц.

## [0.1.0] — 2026-10-24

Первая публичная версия.

### Добавлено

- Скил `papa-seo`: роутер `SKILL.md` и режимы `audit`, `page`, `plan`, `brief`, `write`, `refresh`, `edit`, `links`, `fix`, `measure`, `geo`, `yandex`.
- Политики: безопасность (чужой контент — данные, SSRF, секреты), правила доказательств, лестница полномочий без автопубликации.
- Модули по функциям: технический аудит, индексация, on-page, разметка, скорость, AI-поиск, Яндекс, E-E-A-T, семантика, выдача, внутренние и внешние ссылки, локальное SEO, магазины, hreflang, шаблонные страницы, миграции, логи, измерения, ТЗ, написание, правка, де-AI, заголовки, лендинги, голос, фактчекинг, метрики текста, отчёт.
- Справочники: датированные факты со ссылками на первоисточники, список мифов, ростер ботов с Яндексом, Яндекс-дорожка, типы страниц, русский стиль.
- Шаблоны: `finding.schema.json`, `brief.md`, `report.md`, `project-context.md`, `voice-profile.md`.
- Скрипты на стандартной библиотеке Python: `http_safe.py`, `page_facts.py`, `robots_check.py`, `sitemap_check.py`, `link_graph.py`, `bot_verify.py`, `text_metrics.py`, `deai_scan.py`, `factdiff.py`, и тесты к ним с набором атак.
- `evals/`: сайт-фикстура с заложенными дефектами, ловушками и prompt-инъекцией, ключ ответов, порядок сравнения «модель без скила / со скилом».
- `LICENSE` (MIT), `THIRD_PARTY_NOTICES.md`, `licenses/`, `source.lock.json`.

### Известные ограничения

- Нет рендера JavaScript: проверяется сырой HTML; признаки CSR помечаются, отрендеренный DOM не сравнивается.
- Строки User-Agent для `http_safe.py fetch --ua-of` во встроенной таблице не сверены с документацией вендоров; перед проверкой WAF сверить вручную (сверены в 0.1.1).
- Скрытый текст распознаётся по inline-стилям и известным классам, внешний CSS не учитывается.
- `bot_verify.py` проверяет rDNS только для Googlebot, YandexBot и Bingbot; AI-боты помечаются `needs_ip_ranges`.
- `evals/` подготовлены, но сравнение «без скила / со скилом» на моделях ещё не прогонялось.
- Антивирус и сторонний SAST по пакету не запускались; проверка — тесты, ревью кода и поиск опасных конструкций (см. SECURITY.md).

### Проверено на реальном сайте

- 24.10.2026 — бережный аудит affpapa.org: 15 страниц последовательно с паузой, robots.txt, индекс sitemap. Найденные недостатки скриптов исправлены в этой же версии: пауза между запусками, один запрос на страницу, пакетный режим, ложные срабатывания `hidden_instruction` на русской лексике, лимит шардов sitemap, `words_main`, компактная матрица robots, даты JSON-LD против текста.
