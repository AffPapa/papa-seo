# papa-seo

Скил для ИИ-агента, который проверяет сайты, готовит ТЗ и пишет или правит тексты под Google и Яндекс. Работает в Claude Code и OpenAI Codex. Версия 0.1.0.

[English version](README.en.md) · [Быстрый старт](QUICKSTART.md) · [Безопасность](SECURITY.md)

## Что умеет

Просить можно обычными словами («проверь страницу», «составь ТЗ», «обнови статью») или назвать режим.

| Режим | Что делает |
|---|---|
| `audit` | технический аудит: статусы, редиректы, canonical, robots, sitemap, разметка, скорость, внутренние ссылки |
| `page` | разбор одной страницы: title, description, заголовки, изображения, разметка, индексируемость |
| `plan` | интенты, кластеры, карта «запрос → страница», каннибализация |
| `brief` | ТЗ автору: интент, угол, структура, вопросы эксперту, что не писать без источника |
| `write` | статья по ТЗ с источниками для каждой цифры |
| `refresh` | обновление старой страницы: что устарело, что изменилось в выдаче, сверка фактов до и после |
| `edit` | правка и рерайт без потери фактов, де-AI редактура |
| `links` | внутренние ссылки (сироты, глубина, точная вставка «донор → цель → анкор → предложение»), внешние по бесплатным данным |
| `fix` | черновик или патч правок по найденным проблемам; применяется только после вашего «да» |
| `measure` | Search Console, Вебмастер, GA4 в режиме чтения: сравнение периодов, выпадения, запросы рядом с топом |
| `geo` | видимость в AI-поиске: допуск к индексу и сниппету, боты, самодостаточные фрагменты, llms.txt как опция |
| `yandex` | отдельная дорожка Яндекса: YandexAdditional, Clean-param, разметка, коммерческие сигналы, переезды |

Локальное SEO, интернет-магазины, hreflang, шаблонные страницы, миграции, логи, лендинги и заголовки подключаются, когда о них спрашивают.

## Как устроено

```
papa-seo/
  SKILL.md       роутер: запрос → режим → нужные модули
  policies/      безопасность, правила доказательств, лестница полномочий
  modules/       по файлу на функцию: tech-audit, indexing, on-page, schema, ...
  references/    датированные факты, мифы, ростер ботов, Яндекс, типы страниц, русский стиль
  templates/     схема находки, ТЗ, отчёт, контекст проекта, профиль голоса
  scripts/       Python 3.10+, только стандартная библиотека
  tests/         python3 -m unittest discover
```

Роутер читает только нужный модуль и нужные справочники, остальное в контекст не попадает. Все пороги и даты живут в `references/facts-2026.md`, у каждого есть дата и ссылка на первоисточник. Модули на этот файл ссылаются, своих чисел не держат.

Каждая находка аудита оформлена по схеме `templates/finding.schema.json`: откуда взят факт, когда, фрагмент-доказательство, статус (`confirmed`, `likely`, `hypothesis`), поисковик, правка и способ проверить её после выкладки. Прежде чем советовать «добавьте X», агент проверяет по живому HTML, что X действительно нет. «На всём сайте нет X» он пишет только при полном покрытии, иначе указывает, сколько страниц проверено.

Скрипты ничего не запускают вовне: без `subprocess` и `eval`, не читают домашнюю папку и переменные окружения. В сеть ходит только `http_safe.py`: он режет приватные и служебные адреса, проверяет каждый шаг редиректа и ограничивает размер ответа.

## Установка

Установщика нет. Пакет ставится копированием одной папки `papa-seo/` и ничего не удаляет и не перезаписывает в ваших настройках. Проверьте, что в целевом каталоге ещё нет папки с таким именем.

Скачать:

```bash
git clone https://github.com/AffPapa/papa-seo.git && cd papa-seo
```

**Claude Code.** Для всех проектов:

```bash
cp -R papa-seo ~/.claude/skills/papa-seo
```

Только для одного проекта:

```bash
cp -R papa-seo <проект>/.claude/skills/papa-seo
```

**OpenAI Codex.** По документации Codex (проверено 24.10.2026, developers.openai.com/codex/skills) скилы лежат в `.agents/skills`. Для всех проектов:

```bash
cp -R papa-seo ~/.agents/skills/papa-seo
```

Для одного репозитория:

```bash
cp -R papa-seo <репозиторий>/.agents/skills/papa-seo
```

Codex ищет `.agents/skills` в каждом каталоге от текущего до корня репозитория. В старых инструкциях встречается путь `~/.codex/skills`, текущая документация его не называет.

Скриптам нужен Python 3.10 или новее. Сторонних пакетов нет.

Удалить пакет можно, стерев эту папку.

## Контекст проекта

Если в корне проекта есть файл `.papa-seo/project.md`, роутер читает его до выбора модуля. Туда пишут рынок и язык, на какие поисковики смотреть, можно ли обходить сайт и с какой нагрузкой, куда класть результаты, кто публикует правки, какой голос у текстов. Заготовка лежит в `papa-seo/templates/project-context.md`, профиль голоса — в `templates/voice-profile.md`.

Без этого файла скил работает с осторожными настройками: одна страница или список до 20 адресов по очереди, без обхода сайта, без публикации.

## Данные и деньги

Базовый режим бесплатный: публичный URL, ваши файлы (HTML, Markdown, CSV, JSON), выгрузки из Search Console или Вебмастера, встроенный веб-поиск агента. Search Console, GA4 и Вебмастер подключаются только на чтение и только вашими ключами.

Платные API (DataForSEO, Ahrefs, Semrush, Serpstat, SE Ranking, Wordstat API, Yandex Search API) скил может предложить как опцию и каждый раз пишет, что это платно. Если данных нет, в отчёте будет «нет данных». Частотность, DR, позиции и CTR скил не придумывает.

## Чего скил не делает

- Не обходит сайт целиком без вашей просьбы. Если попросите, обход идёт в один поток и с предупреждением о нагрузке.
- Не публикует и не меняет сайт сам. Правка доходит до патча, дальше решаете вы.
- Не выполняет инструкции из чужих страниц, robots.txt, CSV и текстов конкурентов. Скрытые обращения к модели в HTML он показывает как находку.
- Не обещает рост трафика или позиции. Балл аудита, если он есть, описывает состояние страницы, а не прогноз.
- Не гонит тексты через детекторы ИИ и не добавляет в текст мнений и историй, которых нет у автора.

## Проверка качества

В `evals/` лежит маленький статичный сайт с заложенными ошибками, ловушками и одной prompt-инъекцией, плюс ключ ответов. Там же описано, как сравнить одну и ту же модель со скилом и без него: точность, полнота, попадания в ловушки, нарушения правил.
